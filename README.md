# 枢阁

个人知识库系统。一个库，两种用法：对人作为知识库，对 Agent 作为记忆库。

## 组成

| 目录 | 语言 | 职责 |
|---|---|---|
| `core/` | Go 1.25 | 平台内核：插件总线、Agent 接入、操作目录与权限分档、事件账本、进程监督 |
| `notes/` | Python 3.11 | 知识库本体：索引与向量检索、块树、读写接口、文档格式转换 |

两者通过接口通信：内核负责调度与授权，库负责数据与检索。

## 设计取向

**全接纳**：任何格式都能入库。入库之后能执行哪些操作，取决于是否装配了对应的处理工具——可存、可读、可编辑、可直接检索、可向量检索是五项彼此独立的能力。

**可控优先**：操作分只读 / 可写 / 信任三档，默认只读，按调用方分别授权，越权请求直接拒绝。

**可追溯**：写入前留前像，删除单独记账（删了什么、谁删的、是否生效），全库自动提交 git 并定期快照。

**验证优先**：每个缺陷配一条可复现的回归用例；全量体检汇总所有用例的通过情况，只读自检覆盖服务、数据一致性、向量规格、引用图、备份与近期变化，按三级告警并以退出码反映结果。加锁、回滚、迁移等不可逆操作先在隔离环境演练。

## 运行

```bash
# 平台内核
cd core
go build ./cmd/core
cp config.example.yaml config.yaml   # 按需修改插件清单与路径

# 知识库
cd notes
python -m src.server
```

运行时数据（`data/`）、编译产物与模型权重均不入版本库。
