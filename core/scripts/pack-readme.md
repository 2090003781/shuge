# 枢阁 · 程序包使用说明

**枢阁**是一个**文件管理式 AI 工作台**：软件自带数据库与检索，把内容组织成「文件夹 + 文件」的样子给人看和操作；
不挂载系统文件系统、不把正文散落成磁盘文件；任意格式可进，每种格式按能力配编辑器；**RAG 原生**、**agent 原生**。

| 项 | 值 |
|---|---|
| 打包时间 | {{PACK_TS}} |
| 来源机 | 平台 `D:\core` ｜ 库 `D:\core-notes`（本包内目录名 `core/` 与 `core-notes/`） |
| 组成 | 平台（Go 宿主 + Go 内核 + Python 插件）+ 库（Python 笔记程序） |
| 不含 | **任何数据**（见第三节「包里没有什么」） |

## 怎么启动（就一件事）

> 包根目录有**两个**启动器，按喜好选一个双击：
>
> | 启动器 | 打开成什么 | 适合 |
> |---|---|---|
> | **`启动枢阁-窗口版.exe`** | **本地软件窗口**（原生窗口：标题栏/菜单/任务栏图标/F11 全屏；**没有**地址栏、后退键、标签页） | 日常用（辞玖 2026-10-09 定的方向） |
> | `启动枢阁.exe` | 系统默认**浏览器**里的控制台页 | 手机/远程看、或临时排查 |
>
> 窗口版是自包含单文件（不用装 .NET）；它用系统里的 Edge WebView2 内核渲染界面，
> 全新机器没有那个运行时会弹一句提示 + 一条微软官方下载链接。界面本体与网页版**完全同一份**。
>
> 下面这段以经典版为例（两个启动器的行为一样：把宿主拉起来 → 等就绪 → 打开界面）。
>
> **双击 `启动枢阁.exe`**。等 3~5 秒，浏览器自动打开 <http://127.0.0.1:8790/console>。
>
> 它干三件事：找到 `core\bin\core-host.exe` → 用 `-open-web` 拉起它 → 宿主把「库」与「内核」按序拉起来。
> **已经在跑**的时候点它也不会"没反应"：宿主会直接把控制台页面打开给你。
>
> - 万一 `启动枢阁.exe` 被安全软件拦了：双击旁边的 **`启动枢阁（备用）.cmd`**（内容就一行，能自己看明白）。
> - 想直接从真身启动：双击 **`core\bin\core-host.exe`**，效果一样 —— 它就是宿主本体（唯一启动器）。
> - 包**不带** `core.exe`（内核）：内核由宿主按需拉起，不用你管，也不该由人双击。
> - **解压到哪都能跑**：启动器按自己所在位置找宿主，宿主按自己位置找平台根，库则"挨着平台找"
>   （`<平台>/../core-notes`）。所以**别在压缩包里直接双击**——先完整解压。
> - 真找不到会**说出来**：启动器会在同目录写一份 `启动失败-看这个.txt` 并弹窗告诉你它找过哪些位置。

## 一、三块进程与三个界面

```
        ┌──────────────────────────── 唯一对外地址 ────────────────────────────┐
        │         http://127.0.0.1:8790   （主程序 core-host.exe）              │
        │   /console  主程序页（控制台 / 库 / 内核 三个页签，库与内核是同页 iframe）│
        │   /notes/   库（透明反代到 8848）                                     │
        │   /core/    内核界面（透明反代到 8795）                                │
        └───────┬──────────────────────────────────────────┬──────────────────┘
                │ 1 秒巡检：先库后内核                        │
        ┌───────▼────────┐                        ┌────────▼─────────┐
        │ 库 notes 8848  │                        │ 内核 core 8795   │
        │ 笔记主体：界面  │                        │ 事件总线 / 账本   │
        │ 索引 / 检索     │                        │ 插件监督 / agent 桥│
        │ 引用 / 编辑器   │                        │ 软件操作权限      │
        └────────────────┘                        └──────────────────┘
```

| 进程 | 是什么 | 端口 | 谁拉起 | 能不能停 |
|---|---|---|---|---|
| **主程序** `bin/core-host.exe` | 本体、前门、整体生命、保活巡检、日志、平台自检、主题真相 | **8790** | 计划任务每 2 分钟保活 / 双击 exe | 可整体关闭，重开即恢复 |
| **库** `core-notes`（Python） | 笔记主体：界面与数据、索引、检索、引用、编辑器 | **8848**（内网） | 主程序（不通就拉；进程一退立刻重拉） | 没有启停；**永远在线** |
| **内核** `bin/core.exe` | 事件总线、账本、插件监督、agent 桥、软件操作权限 | **8795**（内网） | 主程序（1 秒巡检 + 熔断保护） | 可启停，菜单里「启动/停止内核」 |

**启动顺序固定：主程序 → 库 → 内核**（内核起来时库已经在跑，插件一注册就能用）。

## 二、功能列表

### 2.1 库（笔记主体）

**文件与组织**
- 文件夹树 / 文件列表，任意按路径组织；文件与文件夹可新建、改名、移动、删除（回收站）。
- 改名 / 移动**引用自动跟随**；删除后引用处标注「已删除」。
- 多选批量操作：进/出检索库、改标签、移动、设私密 / 移出私密。
- 文件属性（文件头 YAML）：标签、状态、待办 `- [ ]` 可点选，与库元数据联动；右侧栏「属性 / 按属性找」。
- 表格线：csv / tsv / **xlsx 多 sheet** 变成真数据表，界面里只读查询（白名单 + 参数绑定）。

**写与编辑**
- 编辑器按**格式**切换：Markdown / DOCX / PDF 各有各的工具条与能力。
- Markdown 工具条（WPS 风格）：标题、字号、加粗、高亮、列表、待办、引用、缩进、@ 引用笔记、
  链接、代码块、日期、表格、分隔线、查找替换、撤销 / 重做（200 步）。
- **DOCX 引擎**：改文字**不丢样式**；段/表格/图片 + run 级样式读写、查找替换、增删移段。
- **PDF 引擎**：页操作（转 / 删 / 移）、批注增删、**擦字重画**（按原字体字号在原基线重画）、
  全篇查找替换、盖页码 / 印记、合并、扁平化、导出每页 PNG、文字层（行 + span + bbox）。
- 另存 / 导出：md / txt / html（引擎抽）/ pdf（WPS 或引擎）/ 图片。
- 未保存草稿本地留一份，下次打开自动恢复；保存按原格式写回（docx/odt 等保真往返）。
- 大文件、二进制「只存」也能打开（原文件字节直出，按扩展名给 Content-Type）。

**检索与 RAG**
- 顶部一个搜索框两种模式：**全库 / 本篇**。
- 全库检索 = 关键词（FTS）+ 向量 **RRF 融合**，可 rerank、按时间收窄、排除归档。
- 点命中条目：右侧抽屉预览（命中段高亮），**不动编辑器**；抽屉底部「跳到命中」才打开文件并选中。
- 「加入检索 / 移出检索」：文档与二进制默认**只存放**，手动加入才进 RAG（`rag_off` 可见）。
- 注入包：按条目批量取正文组包，供 agent 一次读入。

**引用与关系**
- `@目标` / `@目标#小节` / 路径引用 / 名字带空格的引号形式。
- 反向链接按「引的是我的哪一节」分组；引用页可点一行跳到那一行（选中 + 闪两下）、可「改写…」改名。
- 块树：PDF / DOCX 有页、有层级、有 bbox、有表格；稳定块 ID（内容寻址）。

**私密与安全**
- `visibility` 三档：`public` / `internal`（默认）/ `private`。
- 私密篇**内容加密**（每文件独立内容密钥，主密钥由库密码 KDF 派生），默认**上锁即隐藏**。
- 解锁后本次会话可读可检索，超时自动上锁；搜索框旁的锁条负责上锁 / 解锁 / 设定与更换密码。
- 写入者标签：每篇「最近被谁改过」（来源事件，正文不动）；高风险操作留前像。

**导入与导出**
- 「⬆ 导入」：浏览器选择框选磁盘文件（按字节上传），默认落到当前打开位置，也可像文件管理器那样挑目标。
- 导入后**自动打开**那一篇；投递箱目录拖入即出现。
- 全库快照 / 备份、事件流（`/api/events` 位点续读）、自检。

### 2.2 平台（主程序 + 内核）

**主程序（8790）**
- 整体生命：启动 / 停止内核、重开库、暂停整体（`data/host.paused`）。
- 1 秒巡检：先库后内核；库「忙」不算挂；内核不健康按熔断窗口自动拉起。
- 日志：按来源看（host / core / 各插件），控制台里直接翻。
- 自检：一次跑完写状态；结论不变不留痕，跃迁才记账。
- **主题**：一处切换，主程序页 / 库 / 内核控制台统一；**实时**（SSE 推送）+ 落盘唯一真相（`data/ui-theme.json`）。
- 状态采样缓存：接口快、页面稳。

**内核（8795）**
- 事件总线 + 账本（可查、可校验、可轮转、可重放）。
- 插件监督：注册 / 长轮询 / 崩溃自动重启 / 重启次数与等待可配。
- **插件清单热加载**：新加条目不用重启内核。
- agent 桥：agent 接入（接口插件 + MCP 面 + hook 面）、能力路由、状态。
- **软件操作权限**：4 档（只读 / 可写 / 相信 / 关）+ 按 agent 放开，控制台里点选，即点即存。
- 多格式 MCP 面：JSON / TOML / YAML × 各自形状，一处判断、处处一致。

**agent 接入**
- 模板化：一处描述（`agents/<id>.yaml`）→ 生成「内核侧接口 + agent 侧 MCP/hook」。
- `scripts/agentctl.py`：自动识别装了哪些 agent → 勾选 → 生成并接上 → 验收（真调一次 `brain.health`）。
- 接不了的 agent 给「接入手工单」：把规矩、模板、确切落点、验收标准一次给全，由它自己接。
- **路径不写死**：描述与模板里写 `{{pyw}}` / `{{core}}`，写配置与发手工单时按**本机识别结果**填。

### 2.3 可复跑的自检

一个包里带齐下面这些命令，改完代码随时验（都**不弹黑窗**）：

| 命令 | 验什么 |

## 三、包里有什么、**没有**什么

```
枢阁-程序包/
├─ 启动枢阁-窗口版.exe        ← **本地软件窗口（推荐，双击这个）**
├─ 启动枢阁.exe              ← 经典启动器（开在浏览器里）
├─ 启动枢阁（备用）.cmd        ← 万一 exe 被拦，双击这个
├─ 读我-先看这个.md          ← 本说明
├─ core/                     平台
│   ├─ bin/                  core-host.exe（**唯一的启动器/宿主**；内核 exe 不随包）
│   ├─ cmd/ internal/        Go 源码（自查 / 自己改代码才用得上）
│   ├─ plugins/              内核插件（Python）：agent 接口 / 日志 / 查找 / 上下文包 /
│   │                        转录（会话→笔记）/ 事件总线 / agent 守护 / 接入工具
│   ├─ web/                  内核控制台页面
│   ├─ templates/            agent 接入模板（描述 / 手工单 / MCP / hook / 插件条目）
│   ├─ agents/               agent 描述文件（本机现役那几份，可照抄改）
│   ├─ scripts/              agent 接入 / 体检 / 自测 / 打包脚本
│   ├─ tools/                看门狗（计划任务用）
│   ├─ config.yaml           本机现役配置（路径按本机填的；换机器要改）
│   └─ config.example.yaml   带注释的示例配置
└─ core-notes/               库
    ├─ src/                  正文 / 切块 / 索引 / 检索 / 引用 / 转换 / 引擎 / 服务端
    ├─ web/                  库界面（单文件 index.html）
    ├─ tools/                库的自测与维护脚本
    ├─ docs/                 接口文档（openapi.json / ops.json，由 apidoc.py 生成）
    └─ archive/              已废弃能力的归档（只看历史，不参与运行）
```

**没有**（按打包要求排除）：

- **两边的 `data/` 整个不在**：平台的 `ledger/`（账本）、`logs/`、`transcripts/`（会话转写）、
  `plugins/permissions.json`（权限档位）、`plugins/token.json`（插件面密钥）、`inbox/`、`context/`、`host-cache.json`；
  库的 `index.db`（索引）、`pool/`（向量池）、`前像/`、`snapshots/`、`reports/`、`logs/`。
- **一条笔记正文也没有**：正文在「库 / vault」那个路径下，本来不在程序目录里。
- `.git/`、`__pycache__/`、`*.pyc`、`config.yaml.bak-*`、遗留的旧 exe 与备份。
- 手工开发/运维工具（改 DSH 插件源码、模拟旧链路、回填转录、转录自测等）——它们只在这台机器上由人手动跑。
- **内核 `core.exe`**：不是启动器，由宿主按需拉起；不给它，免得有人误双击（误双击会抢 8795/锁）。
- **`ledgercheck.exe`**（账本校验小工具）：没有任何运行时代码调它，同名能力走接口
  `GET /api/ledger/verify` —— 算多余件，2026-10-07 拿出包。
- **`start_core.py`**（Python 包装）：它只是把宿主"从 Job Object 里脱离"再拉起，本机给 agent 用的；
  拿包的人双击启动器就行 —— 多余件，2026-10-07 拿出包。

## 五、怎么跑起来

1. **放目录**：平台与库**放在一起**最省事（`<你选的目录>\core` 与 `<你选的目录>\core-notes`）；
   宿主会**先看自己旁边**有没有 `core-notes`，有就用它。没有的话回落到本机历史位置
   （`D:\core` / `D:\core-notes`），也可以用 `-notes-dir` 或环境变量 `COREHOST_NOTES_DIR` 指定。
   平台根同样从**可执行件位置**推，不写死盘符。
2. **改配置**：`core\config.yaml` 里 `resources.vault.path` 指到你的库/vault 目录；
   插件条目的 `cwd: "."` 是相对的，不用动。
3. **启动**：双击包根目录的 **`启动枢阁-窗口版.exe`**（想要浏览器就双击 `启动枢阁.exe`；
   或 `启动枢阁（备用）.cmd`，或直接双击 `core\bin\core-host.exe`；都是 GUI/无窗口方式，**不弹黑窗**）。
   窗口版会开一个原生窗口（`core\bin\shuge-app.exe` 是它的本体，菜单里有「在浏览器打开」随时切）。
   经典版则自动打开 <http://127.0.0.1:8790/> ——
   就是主程序页，顶栏三个页签：控制台 / 库 / 内核。
   （宿主会按 **主程序 → 库 → 内核** 的顺序把另两块拉起来，不用手动点。）
4. **关**：控制台里「关闭枢阁」（整体），或单独「停止内核」。库里没有启停这回事。
5. **保活（可选）**：`tools\core_watchdog.ps1` 每 2 分钟看一次，或用任务计划程序挂上
   （`schtasks /Create /TN "core-watchdog" /SC MINUTE /MO 2 /TR "powershell -NoProfile -ExecutionPolicy Bypass -File <平台>\tools\core_watchdog.ps1"`）。
6. **重编 exe（可选）**：`powershell -File scripts\build_exe.ps1 -Target all`（脚本会校验子系统必须是 GUI，防黑窗）。

## 六、界面怎么用（按常见事）

| 想做什么 | 怎么做 |
|---|---|
| 看整体状态 / 启停 | 打开 `http://127.0.0.1:8790/` → 「控制台」页签 |
| 记一条笔记 | 「库」页签 → 左侧树选位置 → 「＋ 新建」→ 写 → 「💾 保存」 |
| 导入磁盘文件 | 「⬆ 导入」→ 选文件（可多选）→ 选落点 → 「开始导入」；导入后自动打开 |
| 找东西 | 顶部搜索框：「全库」搜全库（关键词 + 向量融合），「本篇」只搜当前文档；点结果看右侧抽屉，再点「跳到命中」定位 |
| 让某篇进检索 | 选中 → 「📥 加入检索」（默认不自动进 RAG） |
| 引用另一篇 | 编辑器工具条「@ 引用笔记」，或手写 `@标题#小节`；改名会自动跟随 |
| 改 PDF | 打开 PDF → 工具条：擦字重画 / 批注 / 页操作 / 查找替换 / 盖页码 / 合并 / 导出图片 |
| 改 DOCX | 打开 DOCX → 工具条：改字不丢样式、查找替换、表格与段落操作、另存 / 导出 |
| 转格式 | 「🔄 转换 / 导出」→ 选目标格式 → 产物是**新文件**（不覆盖原篇） |
| 私密 | 选中 → 「设为私密」（不需要解锁）；「解锁」在搜索框旁边的锁条里，解锁后超时自动上锁 |
| 换主题 | 顶栏的「浅白·护眼 / 深色」按钮；三个界面同时实时变 |
| 接一个 agent | 控制台 → 「Agent 接入」→ 勾选 → 生成并接上（接不了的出「接入手工单」，复制给对方） |

## 七、agent 接入（一条命令的事）

```
python scripts\agentctl.py list                            # 看现在装着/接着哪些
python scripts\agentctl.py verify dsh codex reasonix ...   # 逐家验（真调一次 brain.health）
python scripts\agentctl.py add <id> --apply                # 生成接口 + 写 agent 侧 MCP/hook + 验收
python scripts\agentctl.py reload                          # 内核插件清单热加载（不用重启内核）
```

规矩：`agents/<id>.yaml` 是**一处手写**；生成物（MCP 配置片段 / hook 片段 / 内核插件条目）**不要手改**。
路径写成 `{{pyw}}`（本机不弹黑窗的 python）与 `{{core}}`（平台装在哪），写配置时按本机识别结果填。

## 八、数据放在哪（程序与数据分开）

| 位置 | 内容 |
|---|---|
| `core\data\` | `ledger/`（账本）、`logs/`、`transcripts/`（会话转写）、`plugins/`（权限档位、token）、`ui-theme.json`、`inbox/`、`context/` |
| `core-notes\data\` | `index.db`（索引，唯一真相源之一）、`pool/`（向量池）、`前像/`、`snapshots/`、`reports/`、`logs/` |
| 库 / vault 目录（`config.yaml` 里配） | **笔记正文**（含私密篇密文） |

**搬机器**：程序目录可以整个搬；数据目录单独搬；正文目录按 `config.yaml` 指过去。
**备份**：库侧有快照与备份命令；平台侧 `data/ledger` 可直接拷。

## 九、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 有黑窗一闪 | 不该有。跑 `python scripts\check_no_windows.py` 定位；自己写的脚本请用 `pythonw.exe` 或带 `CREATE_NO_WINDOW` |
| 控制台打不开 / 一直转 | 先看 `core\data\logs\host.log`；宿主可能是上一份 exe 崩了 —— 双击 `bin\core-host.exe` 重启即可（单实例锁保证不会堆进程） |
| 内核不在 | 控制台点「启动内核」；或 `curl -X POST http://127.0.0.1:8790/api/core/start` |
| 库不在 | 宿主会在 1 秒内拉起；仍不行看 `core-notes\data\logs` |
| 端口被占 | 宿主会在候选端口里挑；实际端口写在 `core\data\*.port`，也可看日志首行 |
| 换了机器路径不对 | 改 `core\config.yaml` 的 `resources.vault.path`；agent 侧重建：`python scripts\agentctl.py add <id> --apply` |
| 换了机器后 exe 起不来 | 用 `scripts\build_exe.ps1` 在这台机器上重编（Go 交叉编译带 CGO 的依赖会挑机器） |
| 权限档位丢了 | `permissions.json` 属于数据、没随包走：起来是平台默认档，在控制台点选即可 |

## 十、怎么确认包里真没数据

在解压出来的目录里搜这些名字，应当**一条都不命中**（源码里同名文件除外，例如 `internal\pluginauth\auth.go`）：

```
data\   .git   __pycache__   token.json   permissions.json   index.db   *.bak*
```

打包工具自带这条验收（`python scripts\make_program_pack.py`）：必需件缺一个、或混进一个数据件，
都会**当场红**并指名那个文件；此外还会逐个打开包里的 `.json/.jsonl` 做"库内数据形状"检查。
